## How I Make Decisions

I make decisions using a layered approach:
1. **Logic first** — Does it make sense on its face?
2. **Common sense second** — Does it hold up in the real world?
3. **First principles third** — If I strip away assumptions, what's actually true?

For complex problems, I'll tear down the problem and build a scoring rubric to help prioritize options. I don't guess — I structure the decision.
